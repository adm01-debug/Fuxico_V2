# FAQ - Perguntas Frequentes

## Geral

**Q: O que é o FUXICO?**
A: Sistema de rastreamento de emails com analytics avançado.

**Q: É compatível com qual email?**
A: Gmail (extensão Chrome) e qualquer cliente via API.

## Tracking

**Q: O destinatário sabe que está sendo rastreado?**
A: O pixel é invisível, mas boas práticas recomendam disclosure.

**Q: Por que algumas aberturas não são detectadas?**
A: Clientes de email podem bloquear imagens externas.

**Q: Como funciona o self-open detection?**
A: Detectamos por IP e user-agent do remetente.

## Técnico

**Q: Qual o limite de emails?**
A: Depende do plano. Free: 100/mês, Pro: ilimitado.

**Q: Como integrar com meu CRM?**
A: Via webhooks ou integração nativa com Bitrix24.

**Q: A API tem rate limiting?**
A: Sim, 100 requests/minuto por usuário.

# Glossário

## Termos do Sistema

| Termo | Definição |
|-------|-----------|
| **Tracking ID** | Identificador único de rastreamento |
| **Pixel** | Imagem 1x1 invisível para tracking |
| **Open** | Evento de abertura de email |
| **Click** | Evento de clique em link |
| **Bounce** | Email não entregue |
| **Self-open** | Abertura pelo próprio remetente |
| **Unique Open** | Primeira abertura por destinatário |

## Métricas

| Métrica | Fórmula |
|---------|---------|
| **Open Rate** | Opens / Enviados × 100 |
| **Click Rate** | Clicks / Opens × 100 |
| **Bounce Rate** | Bounces / Enviados × 100 |

## Status de Entrega

- `pending` - Aguardando envio
- `sent` - Enviado
- `delivered` - Entregue
- `bounced` - Falhou
- `opened` - Aberto
